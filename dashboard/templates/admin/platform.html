Sign in with Google

One Google OAuth client for the whole platform — users just click “Sign in with Google” to send from their Gmail. Without it they can still send with an app password or any SMTP server.

{{ "Configured (stored encrypted)" if google_configured else "Not configured" }}

  1. In Google Cloud Console, enable the Gmail API for your project.
  2. On the OAuth consent screen, choose External. While the app is in Testing, add each user's Gmail as a test user (max 100; sign-ins expire after 7 days). Publish and verify the app to open it to everyone.
  3. Create a client of type Web application with this authorised redirect URI:
    {{ redirect_uri }}
  4. Download its JSON and upload it here.

Sign in with Microsoft

For Outlook, Hotmail and university Microsoft 365 accounts — most universities. One free app registration for the whole platform; students click “Continue with Microsoft” or “Connect with Microsoft” and send from their own mailbox through Microsoft Graph.

{{ "Configured (stored encrypted)" if ms_configured else "Not configured" }}

  1. In the Microsoft Entra admin center → App registrations (free with any Microsoft account), choose New registration.
  2. Supported account types: Accounts in any organizational directory and personal Microsoft accounts.
  3. Redirect URI, platform Web:
    {{ ms_redirect_uri }}{% if ms_redirect_uri.startswith('http://') %}
    Plain http is accepted only for localhost; in production use your https domain.{% endif %}
  4. Under API permissions → Microsoft Graph → Delegated, add Mail.Send, Mail.Read, User.Read, offline_access, openid, email, profile.
  5. Under Certificates & secrets, create a client secret. Paste its Value and the Application (client) ID below.
  6. Recommended: publisher verification (free with a Microsoft AI Cloud Partner Program ID). Many universities only let students approve apps from verified publishers; otherwise their IT has to approve Ntern once.
